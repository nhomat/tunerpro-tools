=======================================================================
TunerPro Tools Suite - Configuration du menu Custom Tools de TunerPro
=======================================================================

Ce fichier explique EXACTEMENT quoi saisir dans TunerPro RT pour ajouter
chaque outil de la suite a son menu "Custom Tools" (Tools > Custom
Tools > Add/Edit dans TunerPro RT).

Pre-requis : avoir execute build_all.bat puis install_tunerpro_tools.bat
sur une machine Windows, afin que les .exe existent dans :
C:\TunerProToolsSuite\Tools\TunerPro_CustomTools\

Pour chaque outil ci-dessous, TunerPro demande trois champs :
  - Menu Text          : le libelle affiche dans le menu
  - Tool Filename       : le chemin complet vers l'executable
  - Keyboard Shortcut   : un raccourci clavier optionnel (peut rester vide)

=======================================================================
Notes
=======================================================================
- Si le dossier d'installation differe de C:\TunerProToolsSuite, adaptez
  chaque "Tool Filename" en consequence.
- Chaque outil est un executable independant : TunerPro les lance comme
  n'importe quel programme externe et n'a besoin d'aucune autre
  configuration.
- Ces outils sont concus pour l'ANALYSE et la SIMULATION hors ligne. Ils
  ne modifient jamais un fichier BIN original sans creer une copie au
  prealable (voir SAFETY.md dans docs\).
